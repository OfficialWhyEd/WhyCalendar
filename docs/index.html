What you can ask

No commands. Just
plain language.

There is no syntax to learn. Ask as you would ask a colleague who has full access to your calendar.

Focus
"Block every Monday morning for deep work"
Creates a recurring event every Monday at your usual start time. Labels it as focus time. No drag and drop. Done in one sentence.
Rescheduling
"Reschedule tomorrow's 3pm to Friday"
Reads your current calendar, finds the event, checks Friday availability, moves it. Handles conflicts automatically.
Analytics
"How many hours did I spend in meetings this week?"
Scans your week's events, sums up meeting durations, breaks down by type. Answers in plain language with suggestions for reclaiming time.
Scheduling
"Create a workout slot every day at 7am"
Creates a recurring daily event at 7am. Checks for conflicts first. Adapts the time if a slot is already taken.
Planning
"What's my busiest day next week?"
Reads every event next week, calculates committed time per day, ranks them. Tells you where the pressure points are before they hit.
Recap
"Give me a recap of yesterday"
Synthesizes yesterday's events, estimates time allocations, highlights what was completed vs. skipped. Starts your day with full context.
Free-slot detection — the feature that changes everything
"What's free Thursday afternoon for a 2h focus block?"
Reads your real Google Calendar for Thursday. Finds contiguous free slots in the afternoon. Tells you exactly what's available — "You have 3pm-6pm free. Want me to block it for focused work?" If you say yes, it creates the event immediately. This is the core miracle: the AI does not just answer — it acts on your calendar in real time.

Philosophy

01 // REAL CALENDAR

Not a toy — your actual Google Calendar

Most "AI calendar" tools work on a copy of your data, in their own silo. WhyCalendar reads and writes your real Google Calendar directly via OAuth. Events you create through the AI appear on your Google Calendar, in Google, immediately.


When you say "block Thursday afternoon", that block appears on your calendar immediately — visible on every device you have connected to Google Calendar. No import. No sync delay. No separate account.

02 // NATURAL LANGUAGE

No UI clicks required

Say "Block Thursday 3pm for 2 hours". Done. No drag and drop, no date picker, no modal dialogs. The AI understands intent and acts on your calendar directly.

03 // NO API KEY

Claude Pro — zero extra cost

Uses Claude Code CLI as a subprocess. If you have Claude Pro, the AI is completely free. No Anthropic API key, no usage fees, no metered billing per message.

04 // NATIVE macOS

App bundle, menu bar, notifications

Tauri 2 app packaged as a native .app bundle. Native macOS notifications. Menu bar integration. Not an Electron wrapper. Not a browser tab pinned as an app.

05 // TIME INTELLIGENCE

Patterns, not just lookups

AI understands your calendar patterns and proactively spots optimizations — overloaded days, missing recovery time, recurring conflicts. It thinks ahead so you do not have to.

Under the hood

Real engineering.
Real numbers.

01 // SYNC

Google Calendar API v3

Full read and write access via OAuth 2.0 PKCE. Events, recurrences, attendees, time zones — the complete API surface exposed to the AI.

02 // AI

Claude Code CLI subprocess

claude --print invoked as a subprocess. Calendar context injected. Response parsed and acted on. Zero Anthropic API key required.

03 // NATIVE

Tauri 2 — Rust backend

Rust handles OAuth flow, token storage, API calls. React frontend renders the UI. Packaged as a native macOS .app — no Electron overhead.

04 // TIMER

Pomodoro + time tracking

Focus timer attached to calendar events. Logs time per slot. WhySpidey reacts to completions. Daily time summary available on demand.

05 // RECAP

Daily AI recap

Ask for a recap of yesterday or a preview of tomorrow. AI synthesizes your calendar into a readable briefing with priorities and warnings.

06 // NOTIFY

Native macOS notifications

System notifications for upcoming events, Pomodoro completions, and AI-detected conflicts. Respects Do Not Disturb. No browser required.
